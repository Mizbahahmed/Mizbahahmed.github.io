# Mizbah Ahmed Sresto — portfolio

An editable, mobile friendly personal site for GitHub Pages. Open `index.html` in a browser to preview it.

## Publish on GitHub Pages

1. Create a **public** repository named `YOUR_USERNAME.github.io` on GitHub (replace `YOUR_USERNAME` with your GitHub username). For the existing profile link in this site, that would be `Mizbahahmed.github.io`.
2. Upload `index.html`, `style.css`, and `script.js` to the **root** of the repository and commit them. Do not upload the outer `mizbah-portfolio` folder as a single folder.
3. Under **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. Visit `https://YOUR_USERNAME.github.io/` once GitHub finishes publishing. Later edits committed to `main` update the site.

## Edit content

- Headings, biography, research projects, work history, and contact links: `index.html`.
- Publications and thesis: the static `publication-list` section in `index.html`. The Google Scholar profile link is in `index.html`.
- Colors, fonts, spacing, and mobile layout: `style.css`.
- To add photos, create an `images/` folder, upload images, and insert `<img src="images/your-photo.jpg" alt="Description of the photo">` in a project card. Use your own photos or images you have permission to publish; ask people in photos before posting identifiable images.
